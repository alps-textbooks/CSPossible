# CSPossible

CSPossible is an AP CSP curriculum following the [College Board 2027-2028 AP CSP redesign](https://apcentral.collegeboard.org/courses/ap-computer-science-principles/redesign). It is an introductory college-level computer programming course in Python and freely available as an interactive e-book on Runestone at <https://runestone.academy/ns/books/published/cspossible/cspossible.html?mode=browsing>.
